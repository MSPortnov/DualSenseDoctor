# DualSense Doctor

[![build](https://github.com/MSPortnov/DualSenseDoctor/actions/workflows/build.yml/badge.svg)](https://github.com/MSPortnov/DualSenseDoctor/actions/workflows/build.yml) [![License: GPL v3](https://img.shields.io/badge/license-GPL--3.0-blue.svg)](LICENSE)

[English](README.md) | **Русский**

Плагин для [Decky Loader](https://decky.xyz/): геймпад DualSense в SteamOS. Две части в одном плагине:

1. **Лаборатория** подбирает параметры запуска для каждой игры (Proton, переменные `PROTON_*`, Steam Input) на сетке обложек.
2. **Doctor** исправляет Bluetooth-подключение после сна, когда контроллер будит компьютер.

Проверялся с DualSense Edge по Bluetooth на настольном ПК с SteamOS. На других конфигурациях поведение может отличаться, сообщения об ошибках приветствуются (см. [Как сообщить о проблеме](#как-сообщить-о-проблеме)).

## Лаборатория: параметры запуска для каждой игры

Откройте быстрое меню, нажмите «Настроить игры» и выберите игру на сетке обложек (7 в ряд, по алфавиту, как в библиотеке Steam). Обложки берутся из локального кэша Steam и ваших картинок в `userdata/*/config/grid` (так обложки получают не-Steam игры), затем с серверов Steam; если обложки нет, показывается плитка с названием.

Для каждой игры выбирается одна из настроек: нативная поддержка, `PROTON_DISABLE_HIDRAW=1`, эмуляция DualShock 4 и другие, либо «Только Steam Input». Плагин записывает параметры запуска и версию Proton, сам включает или выключает Steam Input и запускает игру.

Steam Input включается только настройкой «Только Steam Input», у остальных он выключен. Плагин всегда записывает явное значение (2 = включено, 0 = выключено), а не «по умолчанию», которое зависит от общих настроек Steam. Если Steam значение не принял, игра не запускается. Если параметры запуска изменены вручную и не совпадают ни с одной настройкой, Steam Input не трогается.

## Doctor: Bluetooth после сна

Проблема: при пробуждении ПК ядро теряет первый пакет контроллера. Компьютер закрывает «пустое» соединение примерно на 4-й секунде, а если связь сохранить, контроллер сам разрывает её примерно на 28-й секунде. Кроме того, Steam может открыть контроллер неверно (заводской цвет подсветки, кнопки A и B перепутаны).

Что делает плагин (всё работает без настройки):

- **Ранний connect:** если HID-канал не появился примерно за секунду, плагин открывает его сам.
- **Ответ контроллеру:** отправляет L2CAP-ответ «pending» на потерянный запрос 4 раза с интервалом 15 секунд, это убирает обрыв на 28-й секунде.
- **Подхват Steam:** HID-устройство создаётся сразу (связи оно нужно), но его драйвер отключается примерно на 5 секунд, поэтому Steam впервые видит контроллер, когда уже не занят пробуждением, и открывает его правильно (одно уведомление «подключён»). Если Steam всё же открыл его неверно (в журнале Steam «Invalid or missing unit serial number»), плагин переподключает драйвер, до двух раз.
- Дополнительно: не даёт Bluetooth-адаптеру засыпать (autosuspend) и записывает HCI-трассу (btmon) для диагностики.

Известное ограничение: из-за шага подхвата контроллер начинает работать примерно через 5–6 секунд после пробуждения, нажатия раньше этого игнорируются.

## Установка и обновление

Четыре способа, выбирайте удобный. Та же команда (или тот же ZIP) ставит плагин и позже обновляет его,
настройки сохраняются, потому что хранятся вне папки плагина.

**1. С GitHub, прямо на SteamOS-приставке.** Переключитесь в режим рабочего стола, откройте терминал (Konsole) и выполните:

    curl -fsSL https://raw.githubusercontent.com/MSPortnov/DualSenseDoctor/main/install.sh | bash

Скрипт скачивает последний релиз, проверяет его SHA-256 и ставит в `~/homebrew/plugins/DualSense Doctor`.
В первый раз понадобится пароль пользователя `deck` (если не задавали, задайте командой `passwd`): его спросит `sudo`.
Скрипт короткий, [прочитайте его](install.sh) перед запуском.

**2. С GitHub, с другого компьютера (macOS или Linux).** Один раз на приставке включите SSH и посмотрите её IP-адрес:

    sudo systemctl enable --now sshd
    ip -4 addr | grep inet

Затем на своём компьютере (вместо `192.168.1.101` подставьте свой IP):

    ssh -t deck@192.168.1.101 'curl -fsSL https://raw.githubusercontent.com/MSPortnov/DualSenseDoctor/main/install.sh | bash'

**3. Через Decky, без терминала.** В Decky откройте Настройки > General и включите *Developer mode*. Затем откройте раздел
*Developer*, выберите *Install Plugin from URL* и вставьте:

    https://github.com/MSPortnov/DualSenseDoctor/releases/latest/download/DualSenseDoctor.zip

Можно и скачать `DualSenseDoctor.zip` на странице [Releases](https://github.com/MSPortnov/DualSenseDoctor/releases)
и выбрать в том же разделе *Install Plugin from ZIP*.

**4. Из исходников.** Нужен компьютер с Mac или Linux и SSH-доступом к приставке (Node.js 18+ и
[pnpm](https://pnpm.io/) 9 ставятся сами, если их нет):

    git clone https://github.com/MSPortnov/DualSenseDoctor.git
    bash DualSenseDoctor/deploy.sh 192.168.1.101

Адрес запоминается в `~/.dsd_host`. Обновление: `cd DualSenseDoctor && git pull && bash deploy.sh`.
Прямо на приставке то же делает `bash update.sh`. Оба скрипта собирают плагин
(`pnpm install --frozen-lockfile`, `pnpm run build`) и устанавливают его; Node.js ставится в `~/.local/node`, pnpm в `~/.local/pnpm`.

Установка и обновление перезапускают Decky Loader, и Steam при этом перезагружает свой интерфейс. Если сразу после
обновления магазин Steam откроется пустым, откройте его ещё раз: к плагину это не относится (то же бывает после
`sudo systemctl restart plugin_loader`).

## Зачем плагину root

В `plugin.json` указан флаг `root`. Он нужен Doctor для действий, недоступных обычному пользователю:

- запись в `/sys`, чтобы отключить и вернуть драйвер HID (`unbind` / `bind`) и выключить USB-автосон Bluetooth-адаптера;
- открытие сырого HCI-сокета для отправки L2CAP-ответа;
- запуск `btmon` для необязательной HCI-трассы.

Одной Лаборатории root не требовался бы. Ничего не скачивается и никуда не отправляется, все изменения перечислены выше.

## Как сообщить о проблеме

В плагине откройте «Настройки Bluetooth» и нажмите «Собрать отчёт Bluetooth». Отчёт сохраняется в домашней папке пользователя SteamOS (`dualsense-doctor-ДАТА-summary.txt` и полный архив `.tar.gz`). Чтобы скачать его на другой компьютер:

```bash
bash deploy.sh АДРЕС fetch   # отчёт и архив попадут в ~/Downloads
bash deploy.sh АДРЕС logs    # логи Decky и плагина попадут в ~/Downloads/dsd-diag.txt
```

В отчёте есть системные журналы и адреса Bluetooth-устройств, поэтому просмотрите его, прежде чем публиковать. Собственные логи плагина лежат в `~/homebrew/logs/DualSense Doctor/`.

## Настройки

Doctor работает без настройки. В разделе «Настройки Bluetooth» есть переключатели для каждого исправления (ранний connect и его задержка, ответ контроллеру, подхват Steam, запрет автосна адаптера, HCI-трасса). Язык («Авто» берёт язык Steam, English или Русский) выбирается внизу панели. Он действует на интерфейс, на собственные сообщения плагина (`events.log`, заметки в сеансах) и на отчёт Bluetooth, поэтому отчёт пишется на выбранном вами языке. Сообщения вспомогательных скриптов выводятся на языке системы.

## Для разработчиков

- Бэкенд: `main.py` (только стандартная библиотека Python, работает от root). Фронтенд: `src/` (React и TypeScript,
  собирается командой `pnpm run build` в `dist/`).
- Bluetooth-движок следит за контроллером через BlueZ (`dbus-monitor`, `bluetoothctl`), журнал ядра и HCI-трассу (`btmon`).
- CI: `build.yml` собирает фронтенд и компилирует `main.py` при каждом пуше и pull request.
- Релиз: поднимите версию в `package.json` **и** `VERSION` в `main.py`, добавьте запись в `CHANGELOG.md`, закоммитьте,
  затем `git tag v1.2.3 && git push origin v1.2.3`. GitHub Actions соберёт плагин и приложит `DualSenseDoctor.zip`
  (имя всегда такое, плюс файл `.sha256`) к новому релизу; сборка завершится ошибкой, если тег, `package.json` и `main.py` расходятся.
- Коммитьте `pnpm-lock.yaml`: сборка использует `pnpm install --frozen-lockfile`.
